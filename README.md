# Coffee Archive

커피 기구의 사양을 한자리에 모아 두고, 같은 종류끼리 나란히 비교해 보는 자료 모음입니다.
드리퍼 하나를 고를 때마다 흩어진 스펙을 다시 찾아보는 게 번거로워서 만들었습니다.

## 담긴 것

- **스토어** — 종류·브랜드·재질·난이도로 걸러 보는 목록
- **제품 상세** — 사양표, 써 보면 좋은 점과 감안할 점, 호환 규격
- **비교하기** — 같은 종류끼리 최대 4개까지 나란히, 차이 나는 항목만 보기

비교함에 담은 목록은 브라우저 `localStorage`에 남습니다. 서버도 데이터베이스도 없고,
제품 데이터는 전부 [`src/lib/products.ts`](src/lib/products.ts) 한 파일에 있습니다.

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 열립니다.

## 사양 데이터에 대해

사양과 가격은 제조사와 공식 수입사가 공개한 자료를 기준으로 정리했습니다.
제조사가 값을 밝히지 않은 항목은 `제조사 미표기`로, 그 제품 구조상 존재하지 않는 항목은
`해당 없음`으로 적어 두었습니다. 유통 시기나 생산 로트에 따라 실제 제품과 다를 수 있으니
구매 전에 판매처에서 한 번 더 확인해 주세요.

잘못된 값이나 빠진 제품을 발견하면 이슈로 알려주세요.
